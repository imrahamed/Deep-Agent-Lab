# Write an evidence brief

1. Restate the question in one line. For a multi-topic question, keep a separate
   retrieval query for each topic.
2. Use the evidence returned by the search tool to build findings. Put the exact
   citation string from the tool next to the claim it supports.
3. List gaps separately. Name the policy or record that would resolve each gap.
4. Close with next steps and distinguish proposed steps from documented requirements.
5. If the user requests saving, send the finished Markdown to save_brief. A human
   will see the proposed title and content before the brief is stored.
